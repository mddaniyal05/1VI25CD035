26. Remove Duplicates from Sorted Array


class Solution(object):
    def removeDuplicates(self, nums):
        
        first=1
        val=nums[0]
        n=len(nums)
        for i in range(1,n):
            if nums[i]!=val:
                nums[first]=nums[i]
                first+=1
                val=nums[i]

        return first


Input
nums =
[1,1,2]
Output
[1,2]
Expected
[1,2]
